# Feature Engineering Lab

A practical collection of feature engineering techniques and preprocessing workflows used to improve the performance of machine learning models.

This repository serves as a learning resource and reference for preparing high-quality datasets before model training.

## Topics Covered

- Data Cleaning
- Missing Value Imputation
- Feature Scaling
  - Standardization
  - Normalization
- Categorical Encoding
  - Label Encoding
  - One-Hot Encoding
  - Ordinal Encoding
- Date & Time Feature Extraction
- Feature Selection
- Dimensionality Reduction
- Outlier Detection & Treatment
- Handling Imbalanced Data
- Feature Transformation
- Scikit-learn Pipelines
- ColumnTransformer

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Purpose

The objective of this repository is to demonstrate practical feature engineering techniques commonly used in data science and machine learning workflows. Each notebook focuses on a specific concept with clear explanations and hands-on examples.

Whether you're preparing for interviews, Kaggle competitions, or production ML projects, this repository provides a structured reference for effective feature engineering.
